These three binary regression fixtures are copied unchanged from
https://github.com/WizardMac/ReadStat/tree/b05b645661779ce1863d9fa35a84a7542027085a/resources
under ReadStat's MIT license (retained at `src/readstat/LICENSE`).

- `strl_119.dta`: format 119 references resolve to `third`, `fourth`.
- `trailing_blanks_118.dta`: significant blanks survive as `a     `, `b  `, and an empty string.
- `binary_strl_118.dta`: binary string records do not disrupt subsequent references (`bin`, `hello`).

Expected values come from upstream's `src/test/test_list.h` at the same revision.
The additional generated 20,001-row tests exercise DDIwR's actual parallel workers.

`compression_type_0x06.sas7bdat` is also copied unchanged from those pinned
upstream resources under the same MIT license. It has five rows and three
columns, including compressed and moved row records. Inspection tests corrupt
a compressed observation in a temporary copy: inspection must still return
the original definitions and count, while an ordinary import must fail.

`timestamp_epoch.por` is a generated 656-byte fixture from the embedded
ReadStat POR writer (unchanged from the pinned upstream revision). It contains
one numeric variable `ANSWER`, labelled `Answer`, with values 1 and 2. The writer
was given timestamp 0 with TZ=UTC: the date/time fields are `19700101` and
`000000`. This fixture checks that POR's mandatory creation date is retained at
the Unix epoch and does not create a modification timestamp. Tests read the
saved fixture directly; they require no POR writer or external software.


`sas94-m9-reference.sas7bdat` and `sas94-m9-reference.sas7bcat` were generated
by SAS itself, not by ReadStat, on 2026-10-20 UTC (2026-10-19 local). The runtime
was SAS 9.04.01M9P06052025, Linux x86-64, UTF-8, through SAS OnDemand for
Academics. They contain only synthetic values and definitions. The exact
creation statements and the external interoperability results are recorded in
`tools/readstat/interop/diagnose.sas` and `tools/readstat/interop/README.md`.
The binary files are copied unchanged from that SAS session.

The five data rows contain a 40-byte character variable and a numeric date
with the `DATE9` informat and custom `REFDATE` label format. The date values
are SAS day 3653 (R epoch), system missing, `._`, `.A` and `.Z`. Catalog definitions
also include unused dates before/at the SAS epoch, character leading spaces,
blank keys and Unicode. `test-sas-actual-fixture.R` checks ordinary/date label
units, native missing identities, independent character labels, row windows
and metadata-only inspection. `test-sas-native-missing.R` additionally checks
exported row bytes against the native payloads in this unchanged fixture,
all missing tags at widths 3–8 and compatibility with older ASCII payloads.
The corrected missing-value writer passed a second actual SAS run documented
in the interoperability report. The corrected catalog writer subsequently
passed SAS-native fixture comparisons and the complete paired-export run.
